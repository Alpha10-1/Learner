# Mastery Queue

Local-first PWA that turns the Skills Mastery Roadmap into a daily queue of ~25-minute lessons.
Scope, architecture, conventions and milestones live in [CLAUDE.md](CLAUDE.md).

```bash
npm install     # if npm 10 crashes with "edgesOut", use npm 11: npx npm@11 install
npm run dev     # http://localhost:5173
npm test        # vitest
npm run build   # typecheck, vite build, size budgets (preview with: npm run preview)
```
